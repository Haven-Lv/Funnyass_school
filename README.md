> 上游原话保留：这个项目是 **Vibe Coding** 产物，代码质量与实现方式未必成熟，欢迎 Issue、测试与改进。

“睿智校园”是“趣智校园”的第三方精简版，一个面向校园公寓淋浴场景的精简 Android 客户端，目标是保留登录、余额查询和蓝牙淋浴控制等常用功能，减少与核心使用流程无关的界面干扰。

本 fork 在 0.1919 基础上做了蓝牙稳定性、设备识别与日志排查方面的增强，当前版本 **0.1920**。

### 收藏与设备档案

- 收藏按 MAC 保存（`SharedPreferences: qzxy_lite / favorite_devices_v1`），与账号解耦，换号登录仍在。
- 设备档案记录服务器返回的房间名，180 天后过期；换表/改房间名后重新连接即覆盖。
- 蓝牙广播名并不可靠（很多水表不广播名称，`KLCXKJ-Water` 也没有区分度），所以列表优先显示「已保存的房间名」，其次才是广播名，最后才是「未命名设备」。

### 连接状态

扫描到的设备点击后进入状态机：

```
未选择 → 已选择 → 连接中… → 已连接·读状态 → 已连接（可开始）
                        ↘ 连接失败（显示 GATT status，可直接重试）
```

连接前会 `disconnect/close` 旧的 GATT 客户端，失败分支同样关闭，因此不会再出现「点几次就再也连不上、必须杀进程」的情况。

### 日志与排查

- 「运行日志」标题右侧：`开启日志 / 关闭日志`、`清空`、`导出`。
- 开启后记录：扫描结果、每次连接尝试、GATT status、服务/通知、每帧 TX/RX 十六进制、结算错误码、界面状态变化。
- 日志同时写入 `Android/data/com.funnyass.miuix/files/logs/qzyy.log`，杀进程不丢；1 MB 滚动，最多两份。
- 导出支持「保存为文件」（系统文件选择器）或「复制到剪贴板」；文件头包含机型、Android 版本、App 版本、当前状态。
- 仍保留 `adb logcat -s QZXY` 与 `127.0.0.1:8080` 调试端口（`/log`、`/status`、`/cmd`）。

### 结算说明

- 开始洗澡时一次预扣（本设备为 3.00 元），停止时按实际用量结算，多退少补。
- 停止瞬间的上传可能被服务端以 `226 加密校验失败` 拒绝（设备记录尚未落盘完成，约 20 秒后才稳定）。
- **这是可恢复的**：下次连接 103 时，设备处于「状态 3（有遗留数据）」，App 会自动采集、上传、写回，未用完的预扣随之退回。
- 因此 0.1920 版停止后直接显示「已停止供水」，不再把这次延迟结算当成错误提示。

## 当前状态

当前版本 **0.1920**（versionCode 1920）。项目仍在测试中，可能存在不稳定、设备不兼容、接口变更或异常计费等风险，请先小范围测试，并在确认设备状态后再开始使用。

已实现：

- 手机号验证码或密码登录。
- 查询校园账户余额。
- 扫描并连接附近的蓝牙水控设备（支持按 MAC 手动指定）。
- 开始供水、停止供水和消费记录结算。
- 防重复下单、启动失败预扣回滚及关阀超时重试。
- 登录凭据失效检测和手动重新登录。
- 设备收藏、设备档案、日志开关/导出。
- MIUIX 风格的精简界面，无广告模块。

暂未提供：

- 充值功能。
- 微信小程序版本。
- 启动时自动重连上次设备（可在后续版本加入）。

## 使用方法

1. 从 [Releases](https://github.com/Haven-Lv/Funnyass_school/releases) 下载 `Ruizhi-Campus-0.1920.apk` 安装；也可以用 Android Studio 自行构建。
2. 打开“睿智校园”，使用校园账户登录。
3. 按系统提示授予蓝牙或“附近的设备”权限，并确保蓝牙已开启。
4. 点击「扫描附近设备」。首次使用建议先比对官方 App 里显示的 MAC（如 `C4:7F:0E:20:5B:79`），确认是自己的表；也可以直接把 MAC 填进输入框后点「连接设备」。
5. 点击对应设备完成连接，等待状态变成「空闲（可开始）」后再点「开始洗澡」。
6. 连接成功后点设备卡片里的「☆ 收藏该设备」，之后在「收藏设备」里可一键直连。
7. 使用结束后点「停止供水」。若页面显示「已停止供水」而余额暂未结算，下次连接该设备会自动完成结算并退回未用金额。

登录和余额查询均使用趣智校园官方服务接口。本项目不会搭建、代理或保存独立的校园账户服务，但登录凭据会保存在 Android 应用私有存储中，用于调用相关接口。

## 构建

建议使用 Android Studio 打开项目，并安装项目所需的 Android SDK。

Windows：

```powershell
.\gradlew.bat :app:assembleDebug
```

macOS / Linux：

```bash
./gradlew :app:assembleDebug
```

当前版本的 APK 默认输出到：

```text
app/build/outputs/apk/debug/睿智校园-<版本号>.apk
```

最低支持 Android 7.0（API 24）。当前 APK 仅包含 `arm64-v8a` 所需的原生库，因此其他 CPU 架构可能无法正常运行。
