“睿智校园”是“趣智校园”的第三方精简版，一个面向校园公寓淋浴场景的精简 Android 客户端，目标是保留登录、余额查询和蓝牙淋浴控制等常用功能，减少与核心使用流程无关的界面干扰。

本 fork 在 0.1919 基础上重做了蓝牙连接管理、设备识别与日志排查，当前版本 **0.1924**。

### 连接与占用管理

```
未选择 → 已选择 → 连接中… → 已连接·读状态 → 已连接（可开始）
                        ↘ 连接失败（附原因，可直接重试）
```

- **超时策略**：设备最近 30 秒内有广播 → 15 秒超时（再重试 1 次）；没有广播 → 5 秒超时，直接提示“可能正被别人的手机连着”。
- **释放策略**：结算完成、关阀、结算失败都会在 1.2 秒后自动断开，避免“洗完不释放、别人连不上”。
- **断开闩锁**：手动点「断开连接」后，BleManager 会记住 `manualStop`，所有延迟重试作废，不会自动连回去。
- **占用判定**：查询到 `state=1` 且 `accountId` 不是自己 → 弹窗选择断开或强制停止；对方的预扣/记录由对方下次连接自行结算。
- **遗留记录**：`state=3/6` 表示设备有未结算记录；本版直接代办结算以释放设备，结算失败才断开并在下次连接重试。

水表同一时间**只允许一台手机连接**。它被连着时会停止广播，因此“扫描列表里没有这台表”通常等价于“正被别的手机占用”，而不是信号差。

### 收藏与设备档案

- 收藏按 MAC 保存（`SharedPreferences: qzxy_lite / favorite_devices_v1`），与账号解耦，换号登录仍在。
- 设备档案记录服务器返回的房间名，180 天后过期；换表/改房间名后重新连接即覆盖。
- 蓝牙广播名不可靠（很多水表不广播名称，`KLCXKJ-Water` 也没有区分度），列表优先显示已保存的房间名，其次广播名，最后「未命名设备」。

### 结算说明

- 开始洗澡时一次预扣（本设备 3.00 元），停止时按实际用量多退少补。
- 停止瞬间的采集/上传可能被服务端以 `226 加密校验失败` 拒绝，原因是从**同一条连接**里读到的记录还没稳定；重新建立连接后再采集就能成功。
- 因此本版的行为是：停止时上传不成功就显示「已停止供水」并释放设备；下次连接该表时设备处于 `state=3/6`，会先结算，再允许开阀。
- 未用完的预扣在结算成功后自动退回；如果一直不连接该表，这笔预扣会暂时占着。

### 日志与排查

- 「运行日志」标题右侧：`开启日志 / 关闭日志`、`清空`、`导出`。
- 记录内容：扫描结果（MAC/RSSI/广播名/是否已保存）、每次连接尝试与超时长度、GATT 状态、服务/通知、每帧 TX/RX 十六进制、结算错误码、界面状态变化。
- 日志同时写入 `Android/data/com.funnyass.miuix/files/logs/qzyy.log`，杀进程不丢；1 MB 滚动，最多两份。
- 导出支持「保存为文件」（系统文件选择器）或「复制到剪贴板」；文件头包含机型、Android 版本、App 版本、当前状态。
- 仍保留 `adb logcat -s QZXY` 与 `127.0.0.1:8080` 调试端口（`/log`、`/status`、`/cmd`）。

## 当前状态

当前版本 **0.1924**（versionCode 1924）。项目仍在测试中，可能存在不稳定、设备不兼容、接口变更或异常计费等风险，请先小范围测试，并在确认设备状态后再开始使用。

已实现：

- 手机号验证码或密码登录、余额查询。

- 充值功能。
- 微信小程序 / iOS 版本。
- 启动时自动重连上次设备（刻意不做：自动连接会抢占水表）。

## 使用方法

1. 从 [Releases](https://github.com/Haven-Lv/Funnyass_school/releases) 下载 `Ruizhi-Campus-0.1924.apk` 安装；也可以用 Android Studio 自行构建。
2. 打开“睿智校园”，使用校园账户登录。
3. 授予蓝牙 / “附近的设备”权限，确保蓝牙已开启。
4. 点「扫描附近设备」。首次使用建议先比对官方 App 里的 MAC（如 `C4:7F:0E:20:5B:79`）确认是自己的表；也可以直接把 MAC 填进输入框后点「连接设备」。
5. 点击设备连接，等待状态变成「空闲（可开始）」后再点「开始洗澡」。
6. 连接成功后点设备卡片里的「☆ 收藏该设备」，之后可在「收藏设备」里一键直连。
7. 使用结束点「停止供水」。显示「结算完成 · 已释放设备」即完成；若显示「已停止供水」，下次连接该表会自动补结算并退回未用金额。
8. 如果提示“设备正被其他账户使用”，可选择断开，或（确认无人时）强制停止对方用水。

登录和余额查询均使用趣智校园官方服务接口。本项目不会搭建、代理或保存独立的校园账户服务，登录凭据保存在 Android 应用私有存储中。

## 构建

建议使用 Android Studio 打开项目，并安装项目所需的 Android SDK。

Windows：

```powershell
.\gradlew.bat :app:assembleDebug
```

macOS / Linux：

```bash
./gradlew :app:assembleDebug
```

输出：

```text
app/build/outputs/apk/debug/睿智校园-<版本号>.apk
```

最低支持 Android 7.0（API 24）。当前 APK 仅包含 `arm64-v8a` 原生库，其他 CPU 架构可能无法运行。
